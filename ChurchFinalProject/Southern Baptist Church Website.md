Southern Baptist Church Website
This is an interactive web application for the Southern Baptist Church. It includes features like prayer requests, testimonies, volunteer opportunities, sermon lists, and dynamic map integrations to enhance the user experience. The website is built using HTML, CSS, and JavaScript.

Features
Dynamic Greeting: Personalized greeting based on the time of day.
Prayer Requests: Users can submit prayer requests with an option to remain anonymous.
Testimonies: Users can submit their personal stories and see others' testimonies.
Volunteer Opportunities: Users can sign up for various volunteer roles.
Interactive Map: Displays the church location and services nearby.
Form Validation: Real-time validation for all forms to ensure proper submission.
Technologies Used
HTML5: For structuring the content.
CSS3: For styling and responsive design.
JavaScript: For dynamic and interactive functionality (forms, validations, etc.).
